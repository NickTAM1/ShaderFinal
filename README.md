This project shows five different ways I used shaders to change how objects look and move in a game.



Pulsing Cube: A box that breathes in and out.



Color Sphere: A ball with moving rainbow colors.



Glowing Item: A cylinder with bright, glowing edges.



Wavy Water: A surface that flows and moves up and down.



Dissolve Effect: An object that slowly disappears with a glow.



Camera Lock: Fixed the settings so the screen never goes dark.
